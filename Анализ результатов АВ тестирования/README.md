
# Анализ A/B-теста рекомендательной системы

## Описание проекта

Этот проект выполнен на датасете развлекательного приложения с бесконечной лентой, похожей на приложения с короткими видео. В приложении реализованы две модели монетизации:

- Подписка без рекламы
- Бесплатное использование с показом рекламы

Команда разработчиков предложила новый алгоритм рекомендаций. Цель проекта — оценить, делает ли он ленту более привлекательной для пользователей. 

---

## Используемые данные

Проект использует следующие CSV-файлы:

- `sessions_project_history.csv` — исторические данные с 2025-08-15 по 2025-09-23
- `sessions_project_test_part.csv` — данные за первый день теста: 2025-10-14
- `sessions_project_test.csv` — полные данные по тесту: 2025-10-14 по 2025-11-02

Каждая таблица содержит:

- `user_id`, `session_id`, `session_date`, `session_start_ts`, `install_date`
- `session_number`, `registration_flag`, `page_counter`
- `region`, `device`, `test_group` (в тестовых данных)

---

##  Основные задачи проекта

### 1.  Анализ исторических данных
- Построить графики числа уникальных пользователей и зарегистрированных пользователей по дням
- Построить график доли зарегистрированных пользователей
- Оценить долю «хороших» сессий (с ≥4 страницами) по дням

### 2. Расчёт параметров A/B-теста
- Вычислить среднее дневное количество пользователей
- Рассчитать длительность теста, исходя из размера выборки и трафика

### 3.  Проверка корректности A/B-теста
- Проверить равномерность распределения пользователей по группам A и B
- Вычислить процентную разницу по числу пользователей
- Проверить независимость выборок и отсутствие пересечений
- Проанализировать распределение по регионам и устройствам

### 4.  Финальный вывод
- Сделать заключение о корректности проведения теста
