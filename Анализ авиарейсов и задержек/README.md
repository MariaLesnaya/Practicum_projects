#  Анализ авиарейсов и задержек

##  Описание проекта

В рамках проекта проводится исследование авиарейсов из Нью-Йорка с целью анализа факторов, влияющих на задержки рейсов, времени перелёта, сезонности и распределения вылетов. Исследование опирается на реальные данные о рейсах и проводится с использованием инструментов анализа данных и визуализации.

---

##  Задачи исследования

### 1.  Вероятность задержки по направлениям
- Определить 10 самых популярных аэропортов назначения из Нью-Йорка.
- Для каждого — рассчитать вероятность задержки прилёта 
- Построить столбчатую диаграмму с аэропортами на оси X и вероятностью задержки на оси Y.
- Выявить аэропорт с **наибольшей** и **наименьшей** вероятностью задержки среди этих 10.

### 2.  Распределение времени перелёта до Сан-Франциско (SFO)
- Построить **нормированную гистограмму** времени перелёта до SFO.
- Оценить параметры нормального распределения (среднее и стандартное отклонение).
- Определить диапазон, в котором с вероятностью 95% лежит время полёта.

### 3. Пиковые часы вылета из JFK
- Построить распределение количества вылетов по часам.
- Найти два пиковых часа: **до полудня** и **после полудня**.
- Рассчитать среднюю задержку вылетов в каждый из пиковых часов.
- Сравнить, в какой из часов задержки выше.
- Проверить статистическую значимость различия.

### 4.  Стандартное отклонение vs расстояние
- Рассчитать стандартное отклонение времени перелёта для каждого аэропорта назначения.
- Построить **точечную диаграмму** зависимости стандартного отклонения от расстояния.
- Построить **модель линейной регрессии**.
- Уточнить модель, добавив дополнительные признаки, и сравнить точность моделей.

##  Используемые библиотеки

- `pandas`, `numpy` — обработка данных  
- `matplotlib`, `seaborn` — визуализация  
- `scipy.stats` — статистика  
- `sklearn` — линейная регрессия, кластеризация  
- `statsmodels` — расширенная статистика и регрессия
